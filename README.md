# dayflower's Scoop Bucket

[![Tests](https://github.com/dayflower/scoop-bucket/actions/workflows/ci.yml/badge.svg)](https://github.com/dayflower/scoop-bucket/actions/workflows/ci.yml) [![Excavator](https://github.com/dayflower/scoop-bucket/actions/workflows/excavator.yml/badge.svg)](https://github.com/dayflower/scoop-bucket/actions/workflows/excavator.yml)

A personal bucket for [Scoop](https://scoop.sh), the Windows command-line installer.

## How do I install these manifests?

```pwsh
scoop bucket add scoop-bucket https://github.com/dayflower/scoop-bucket
scoop install scoop-bucket/<manifestname>
```
